# Student Performance MLOps

Проект является MLOps-доработкой исходного исследовательского notebook `model_2025_final_v3.ipynb`. Логика notebook была перенесена в модульный Python-проект: подготовка данных, feature engineering, обучение LightGBM-модели, сохранение артефактов, REST API для предсказаний и базовое логирование/мониторинг.

## Что делает проект

Система прогнозирует будущий средний балл студента на основе:

- истории успеваемости по предыдущим семестрам (`history_mean`, `last_mark`);
- результатов ЕГЭ, развернутых в признаки `EGE_*`;
- курса обучения;
- подразделения/института студента.

Целевая переменная — ожидаемый GPA следующего семестра.

## Связь с исходным notebook

Исходная версия модели находилась в `model_2025_final_v3.ipynb` и включала:

- нормализацию названий семестров;
- перевод оценок в числовую шкалу;
- расчет GPA по студенту и семестру;
- разворот ЕГЭ в отдельные признаки;
- генерацию обучающих строк по схеме “прошлые семестры -> следующий семестр”;
- обучение LightGBM-модели.

В рамках доработки эта логика перенесена в production-like структуру:

- `src/features.py` — формирование признаков из notebook;
- `src/train.py` — воспроизводимый training pipeline;
- `src/predict.py` — загрузка модели и инференс;
- `api/app.py` — FastAPI-сервис;
- `src/monitor.py` — логирование предсказаний и заготовка мониторинга;
- `docs/vkr_section_3_mlops.md` — текстовое описание доработки для раздела ВКР.

## Установка

```bash
python -m pip install -r requirements.txt
```

Если команда `pip` не находится, используйте именно:

```bash
python -m pip install -r requirements.txt
```

## Обучение модели

```bash
python -m src.train
```

После запуска создаются артефакты:

- `models/model_v1.pkl` — обученная модель;
- `models/model_v1_metadata.json` — метрики, список признаков и версия модели;
- файлы в `logs/` — логи обучения.

## Запуск API

```bash
python -m api.app
```

После запуска откройте Swagger UI:

```text
http://localhost:8000/docs
```

## Основные endpoints

| Endpoint | Назначение |
|---|---|
| `GET /health` | Проверка состояния API и загрузки модели |
| `GET /model/info` | Информация о модели, признаках и метриках |
| `GET /model/input-example` | Пример корректного JSON для предсказания |
| `POST /predict` | Предсказание для одного студента |
| `POST /predict/batch` | Предсказание для нескольких студентов |
| `GET /predictions/logs` | Просмотр последних логов предсказаний |

## Тестирование

```bash
python test_pipeline.py
```

Скрипт проверяет структуру проекта, зависимости, обучение модели и тестовое предсказание.

## MLOps-компоненты

- **Data layer**: загрузка CSV, подготовка оценок, нормализация семестров.
- **Feature engineering**: GPA по семестрам, `EGE_*`, `history_mean`, `last_mark`.
- **Training pipeline**: воспроизводимое обучение LightGBM через `python -m src.train`.
- **Model registry lite**: сохранение модели и метаданных в `models/`.
- **Inference API**: FastAPI-сервис для одиночных и batch-предсказаний.
- **Logging/monitoring**: логи API, обучения и предсказаний.

Если данные являются персональными или закрытыми, не публикуйте `data/marks_25_hash.csv`, `logs/` и `models/`. Для этого добавлен `.gitignore`. При необходимости можно приложить небольшой обезличенный пример данных отдельно.
